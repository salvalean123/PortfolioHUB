## 🏷️ Versionamento

O projeto segue [Versionamento Semântico](https://semver.org/lang/pt-BR/) e [Conventional Commits](https://www.conventionalcommits.org/pt-br/):

- `feat:` nova funcionalidade · `fix:` correção · `docs:` documentação · `style:` visual · `chore:` manutenção
- Versões marcadas com *tags* (`v1.0`, `v1.1`, …) — veja o [CHANGELOG](CHANGELOG.md).
- Fluxo de colaboração: `main` (estável) ← *pull request* ← `feature/nome-da-feature`.
