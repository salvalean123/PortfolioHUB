# ✅ Lista de Tarefas

Projeto pessoal de estudo: uma lista de tarefas (to‑do list) simples que guarda os dados no próprio navegador.

🔗 **Demonstração:** https://SEU-USUARIO.github.io/PortfolioHUB/projetos-pessoais/lista-de-tarefas/

## Funcionalidades

- Adicionar tarefas
- Marcar/desmarcar como concluída (clique no texto)
- Remover tarefas
- Contador de tarefas pendentes
- Persistência com `localStorage` (as tarefas continuam lá ao recarregar a página)

## Tecnologias

- HTML5
- CSS3
- JavaScript (DOM e localStorage)

## Como executar

Abra o arquivo `index.html` no navegador. Não há dependências.

## O que aprendi

- Manipulação do DOM com JavaScript
- Eventos de formulário
- Armazenamento local no navegador com JSON
