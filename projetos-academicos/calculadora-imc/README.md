# 🧮 Calculadora de IMC

Projeto acadêmico que calcula o **Índice de Massa Corporal (IMC)** a partir do peso e da altura e mostra a classificação segundo a OMS.

🔗 **Demonstração:** https://salvalean123.github.io/PortfolioHUB/projetos-academicos/calculadora-imc/

## Funcionalidades

- Entrada de peso (kg) e altura (m) com validação do formulário
- Cálculo do IMC com uma casa decimal
- Classificação: abaixo do peso, normal, sobrepeso e obesidade (graus I, II e III)

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abra o arquivo `index.html` no navegador. Não há dependências.

## Fórmula

```
IMC = peso / (altura × altura)
```
